# اپ پنجره شناور (Floating Window) — نمونه اولیه

## این اپ چیکار می‌کنه؟
یه **حباب آبی شناور** روی صفحه گوشی نشون می‌ده که:
- با انگشت قابل جابجایی به هر جای صفحه‌ست (drag)
- روی همه‌ی اپ‌های دیگه (حتی وقتی توی یه اپ دیگه هستید) نمایش داده می‌شه
- با زدن ضربدر بسته می‌شه

این پایه و اساس همون قابلیتیه که توی گوشی‌های شیائومی معمولی به اسم "پنجره شناور" یا "Floating Window" وجود داره — فقط اینجا نسخه ساده و آموزشیش رو ساختیم.

## روش اول (بدون کامپیوتر — فقط با گوشی، از طریق GitHub)
این پروژه یه فایل خودکار (`.github/workflows/build.yml`) داره که به گیت‌هاب می‌گه خودش اپ رو کامپایل کنه. مراحل:

1. با مرورگر گوشی وارد [github.com](https://github.com) بشید و یه حساب رایگان بسازید
2. یه ریپازیتوری جدید (New Repository) با نام `FloatingWindowApp` بسازید (Public یا Private، فرقی نداره)
3. همه‌ی فایل‌ها و پوشه‌های داخل این زیپ رو با همون ساختار پوشه‌ای، در همون ریپازیتوری آپلود کنید (گیت‌هاب گزینه "Add file → Upload files" داره؛ پوشه‌ها رو می‌تونید یکی‌یکی بسازید و فایل‌هاشون رو داخلش بریزید)
4. بعد از آپلود، به تب **Actions** بالای صفحه ریپازیتوری برید
5. یه اجرا (workflow run) به اسم "Build APK" می‌بینید که خودکار شروع می‌شه — چند دقیقه صبر کنید تا علامت ✅ سبز بخوره
6. روی همون اجرا کلیک کنید، پایین صفحه بخش **Artifacts** رو پیدا کنید و فایل `app-debug-apk` رو دانلود کنید
7. فایل دانلودشده یه zip هست؛ بازش کنید، فایل `app-debug.apk` داخلشه
8. با فایل‌منیجر گوشی روی APK بزنید تا نصب بشه (شاید لازم بشه اجازه "نصب از منابع ناشناس" رو در تنظیمات گوشی فعال کنید)

## روش دوم (با کامپیوتر — Android Studio)
1. **Android Studio** رو نصب کنید (رایگانه): https://developer.android.com/studio
2. پوشه `FloatingWindowApp` رو با Android Studio باز کنید (File → Open)
3. صبر کنید Gradle خودش وابستگی‌ها رو دانلود و سینک کنه (نیاز به اینترنت داره)
4. گوشیتون رو با کابل USB وصل کنید و حالت **USB Debugging** رو در تنظیمات توسعه‌دهنده (Developer Options) روشن کنید
5. دکمه ▶️ Run رو بزنید

## بعد از نصب روی گوشی
1. اپ رو باز کنید و دکمه "شروع پنجره شناور" رو بزنید
2. اندروید ازتون اجازه "نمایش روی سایر اپ‌ها" (Display over other apps) رو می‌خواد — قبولش کنید
3. برگردید توی اپ و دوباره دکمه شروع رو بزنید
4. حباب آبی رو می‌بینید که روی صفحه شناوره!

## قدم بعدی (برای گسترش اپ)
این فقط اسکلت اولیه‌ست. برای اینکه واقعاً شبیه پنجره شناور شیائومی بشه، می‌تونید:
- به‌جای حباب ساده، یه `WebView` یا میان‌بر به یه اپ خاص (مثل ماشین‌حساب یا یادداشت) داخلش باز کنید
- سایز پنجره رو قابل تغییر (resize) کنید
- چند تا حباب برای چند اپ مختلف بسازید

هر کدوم از این‌ها رو بخواید، بگید تا قدم بعدی رو باهم پیش ببریم.

## محدودیت مهم
این روش **یک پنجره شناور مستقل (مثل ابزارک روی صفحه)** می‌سازه، نه اجرای واقعی یه اپ دیگه داخل اون پنجره. اجرای اپ‌های *دیگر* (نه محتوای خود شما) داخل یک پنجره شناور، از نظر امنیتی توسط اندروید محدود شده و نیاز به دسترسی‌های خاص (مثل Accessibility Service) داره که پیچیده‌تره.
